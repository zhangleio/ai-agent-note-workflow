# Agent Note：仓库文档双语化

Status: implemented

普通文档 hash 校验由[仓库文档 i18n 门禁](2026-08-24-repository-document-i18n-gate.zh.md)部分取代。语言命名、范围、完整 `AGENTS.md` 和同等权威规则继续有效。

[English](2026-08-24-bilingual-repository-documents.md) | 中文

## 问题

仓库指南、根 Agent 指令和示例索引目前只有简体中文。英语读者无法在没有翻译的情况下使用该工作流，而 Agent 和工具仍需要约定的 `README.md` 与 `AGENTS.md` 入口。复制这些篇幅较大的文档之前，仓库需要明确命名和同步策略。

## 决策

仓库为以下三组文档提供同等权威的英文和简体中文版本：

```text
README.md                 README.zh.md
AGENTS.md                 AGENTS.zh.md
examples/README.md        examples/README.zh.md
```

每个无后缀约定入口使用英文，每个 `.zh.md` 对应文件使用简体中文。每份文档都在一级标题紧邻下方提供语言切换器：

```text
English | [简体中文](README.zh.md)
[English](README.md) | 简体中文
```

每对文档同等权威，并保持对应的标题层级、代码块、表格、链接、命令、示例和规范含义。各语言正文可以采用自然表达，不要求逐句直译。当被链接文档存在翻译版本时，相对链接指向相应语言；源文件和共享制品链接保持一致。

`AGENTS.md` 保持完整英文指令文件，因为 Agent 和工具会发现约定文件名。`AGENTS.zh.md` 是供读者使用的完整中文对应版本；`AGENTS.md` 不得变成语言选择跳转页。

这些普通文档没有 `.i18n.yaml` 记录或根翻译 hash 门禁。同步依靠成对语言切换器、对应文档结构、Markdown 诊断、相对链接检查和人工评审。Agent Note 继续使用双语三件套和 Git blob hash 规则。

跨文档引用在存在对应文档时使用相同语言。源代码、早期 Agent Note 历史、包元数据、生成输出和示例项目的项目专用文档不属于本决策范围。

## 考虑过的替代方案

**在约定文件名中保留中文并增加 `.en.md`。** 这能减少当前内容移动，但会使默认 GitHub 和 Agent 入口仅提供中文。对于可复用的公开工作流仓库，英文约定入口具有更好的互操作性。

**把无后缀文件变成语言选择跳转页。** 这可以避免选择默认语言，但 `AGENTS.md` 必须包含可自动发现的可执行指令，而且跳转页会降低两种 README 入口的实用性。

**增加 `.i18n.yaml` hash 记录和根校验脚本。** 这能机械检测漂移，但普通仓库文档的这一方案已被明确放弃。结构评审和链接检查使首次双语文档变更保持轻量；如果漂移成本变高，未来可以用新的 process Note 增加门禁。

**翻译 examples 下的每个 README 和 AGENTS 文件。** 这会把变更扩展到项目专用文档，并要求为每个 demo 单独决策。选定范围先建立双语仓库导航和策略。

## 验证

六份文档均无 Markdown 诊断。结构检查确认三对文档的标题层级和代码围栏数量匹配。能够识别 fenced code 的链接检查确认所有真实相对链接均可解析，独立检查也确认三组成对语言切换器全部有效。

独立双语评审未发现章节、步骤、表格行、命令或链接缺失。评审发现数处中文规范要求强度较弱、可复制英文基线中的 `three pair files` 措辞不准确、英文页面的中文 Note 模板仍使用英文占位说明，以及示例索引存在仅中文一侧的解释。同步修正两侧后，结构、链接、Markdown 和空白检查再次全部通过。人工实施验收接受了最终六份文档。

现有示例项目源码和项目专用文档未修改，因此此前通过的完整检查仍然适用，并且本次没有引入新的示例行为。

## 后果

英语和中文读者现在都有完整的仓库指南、Agent 指令和示例导航。无后缀约定文件提供互操作性更好的英文默认入口，而每个顶层入口都能立即切换到中文。`AGENTS.md` 保持完整，可供自动发现。

没有翻译 hash 门禁时，后续编辑可能只更新一种语言并造成语义漂移。结构检查无法发现 `must` 与 `should` 等规范强度差异，因此仍然需要双语人工评审。GitHub 和大部分自动化工具默认显示英文，而 `AGENTS.zh.md` 主要是面向读者的对应版本。
